# SISB Ministry of Needless Bollocks

An unofficial internal humour site for recording management tasks that create work rather than value.

## Repository

This package is configured for:

`alexhay-SISB/SISB_ministry_of_needless_bollocks`

## Publish with GitHub Pages

1. Create a public repository named `SISB_ministry_of_needless_bollocks`.
2. Upload every file in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.

## Enable adding, editing and deleting

The register is stored in `directives.json`. Create a fine-grained GitHub access token limited to this repository with **Contents: Read and write** permission. On the website, open **System access**, enter the repository details and token, then save the connection.

The token remains in that browser's local storage. It is never committed to the repository. Visitors without the token can read the register but cannot see its management controls.

Because ordinary GitHub Pages sites are public, use nicknames and avoid confidential or personally sensitive information.
